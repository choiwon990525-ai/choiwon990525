# 발로란트 요원 매뉴얼 북 — 작업 규칙

T1 발로란트 아카데미 학생용 요원 매뉴얼 북. 코치(프로게이머 출신)가 검수·작성한다.
- 1층 "요원 카드": 역할 · 장점 · 실전 팁 · 프로 영상 — 초안은 Claude가 쓰고 코치가 검수
- 2층 "맵별 매뉴얼": 맵 > 요원 > 셋업 > 라인전 > 팀 전술 — 히트맵·승률표는 코치 데이터로 Claude가 만들고, 나머지 내용은 코치가 채움. Claude는 틀만.
- 대상: 요원 카드는 API의 전 요원. 맵별 매뉴얼은 우선 7명.
- 우선순위(학생 사용 많은 순): 네온, 제트, 소바, 사이퍼, 체임버 → 페이드, 오멘. 카드도 이 순서로 먼저, 그다음 나머지(타격대 → 척후대 → 감시자 → 전략가).
- 이후 수정 요청 때도 아래 규칙 1~8을 지킨다.

## 1. 요원 카드 톤 (이 느낌 그대로)
코치 메모 원문:
  네온 ( 고속 기어로 채우기 싸움 좋다 / q 즉발 스턴으로 딜레이 좋다 / 연막으로 상대방 고립 좋음 )
  팁: 연막에서 버니합으로 인포 딸 수 있다
  프로 활용 영상: (유튜브 링크)
→ 카드 정리: 장점 "고속 기어(E) → 채우기 싸움 좋음 / 릴레이 볼트(Q) → 즉발 스턴이라 딜레이 좋음 / 추월 차선(C) → 상대 고립 좋음" (코치가 '연막'이라 쓴 게 추월 차선)
- 네온 카드는 코치 메모 내용 그대로 쓰고 빈 데만 채운다.
- 짧은 구. "스킬명(키) → 언제·무슨 싸움에 좋은지", 한 줄 40자 안팎. 현장 용어 그대로(딜레이, 채우기, 인포, 고립, 라인전, 각 등). 교과서식 설명·수치 금지.
- 카드: 한 줄 역할 / 장점 3~4개(스킬 하나당 한 줄) / 팁 1~3개 / 프로 영상 1~2개.
- 확신 없는 건 비우고 REVIEW.md에. 지어낸 팁보다 빈칸이 낫다.

## 2. 데이터 출처 (기억으로 쓰지 말 것)
- 요원·역할군·스킬 공식 한글명·아이콘: https://valorant-api.com/v1/agents?language=ko-KR&isPlayableCharacter=true
- 스킬 키: Grenade=C, Ability1=Q, Ability2=E, Ultimate=X
- 맵 이름·미니맵·콜아웃: https://valorant-api.com/v1/maps?language=ko-KR
- 기준 패치: https://valorant-api.com/v1/version 의 branch (release-13.06 → 13.06)
- 역할군 표기: 타격대(엔트리) / 척후대 / 감시자 / 전략가(연막)
- 스킬명·키는 API와 글자까지 일치. 수치(쿨타임·데미지) 쓰지 않는다.

## 3. 프로 영상 — 링크 지어내기 절대 금지
- WebSearch로 실제 영상만("{영문명} VCT pro highlights", "{영문명} {맵 영문명} pro POV" 등). 최근 1년 우선.
- 링크마다 https://www.youtube.com/oembed?url={URL 인코딩}&format=json 이 200이면 통과 → title·author_name 그대로 기록. 실패하면 버린다.
- Claude는 영상을 못 보니 "2:13에 ○○ 장면" 같은 설명 금지. 제목·채널명만.
- 못 찾으면 유튜브 검색 링크 + "🔍 직접 추가 필요".

## 4. 코치 프로 데이터 (data/raw/, rib.gg 2026 1티어 7개 이벤트, 2026-09-27 수집)
- rib_2026_1티어_원본합본.json — 킬·데스 좌표
  키 "맵|Attack/Defense|kill/death|0/20/60" (시간대 0–20초 / 20–60초 / 60초+)
  값 [x, y, 요원 영문명, 경기id, 라운드]. x·y는 0~100 좌표로 보임
- 프로승률_2026_1티어_전맵.json — 구역 승률
  maps.{맵 영문}.scopes."agent:{한글명}".{A/D}.{"0-20","20-60","60+","all"}.{구역명} = [킬, 데스]
  (scopes에 "all", "role:{역할군}"도 있음)
- 프로승률_2026_1티어_전맵.xlsx — 같은 내용. '읽는 법' 시트에 기준 설명
- 판정 기준(학생 히트맵과 동일): 승률 = 킬 ÷ (킬+데스). 같은 맵·진영·시간대 평균 대비 +3%p 이상 그린존 / −3%p 이하 레드존 / 교전 25 미만 표본 부족
- 구역 이름은 데이터에 있는 한국어 이름 그대로 쓴다. 새로 만들지 않는다.

## 5. 맵별 매뉴얼 페이지 (요원 × 맵, 공격/수비 탭)
맵 목록: 현재 경쟁전 맵 풀을 웹 검색으로 확인해서 코치에게 보여주고 확정받는다. 확정 전엔 만들지 않는다.

[A. Claude가 데이터로 자동 생성]
- 히트맵: 킬(초록)·데스(빨강), 시간대 탭(첫턴 0–20 / 20–60 / 60+ / 전체). PNG를 images/{요원id}/{맵id}/ 에 저장
- 구역 승률표: 구역 · 킬 · 데스 · 승률 · 평균 대비 · 판정(그린존/레드존/표본 부족)
- 프로 사용 비중: 이 맵에서 이 요원의 교전 수 / 맵 전체 교전 수
- 각 블록 위에 "출처: rib.gg 2026 1티어 · 경기 ○ · 교전 ○ · 수집 2026-09-27"
- 데이터 없는 조합은 "프로 데이터 없음". 절대 그림·숫자를 지어내지 않는다.
- 해석(왜 거기 서는지)은 쓰지 않는다 — 그건 코치가 쓴다.

[B. 빈칸 틀 — 코치가 채움, 빈칸엔 회색 "코치 작성 예정"]
- 셋업(라인업): ValoPlant 링크 + 한 줄 설명
- 라인전 위치: 자리 이름 + 한 줄 이유
- 라운드 단계별 스킬: 공격 = 디폴트 / 실행 / 설치 후, 수비 = 기본 자리 / 리테이크
- 팀 전술: 같이 쓰면 좋은 요원 · 콜
- 이 요원이 줘야 할 보고
- 경제별 역할: 피스톨 / 에코 / 풀바이
- 궁극기: 오브 위치 · 쓰는 타이밍
- 시너지·카운터
- 흔한 실수 / 숙제 드릴(커스텀 연습법)
- 반별 단계: 준비반 / 실전반
- 프로 레퍼런스 영상 (3번 규칙 — 이 칸만 Claude가 후보를 채워도 됨)

## 6. 결과물 (valorant-manual/ 안)
- data/agents.js — 요원 카드. `window.AGENTS = [...]` (JSON fetch는 더블클릭으로 열 때 막히니 .js로)
  필드: id, name, role, icon, summary, strengths[{key, skill, text}], tips[], videos[{title, channel, url}], status("AI 초안"/"검수 완료")
- data/manual.js — `window.MANUAL = { 요원id: { 맵id: { attack:{...}, defense:{...}, status } } }`
- data/prostats.js — 4번 데이터에서 만든 승률표·비중 (생성 스크립트도 scripts/에 저장해서 데이터 바꾸면 다시 돌릴 수 있게)
- index.html — 전 요원 카드(역할군 탭·검색). 매뉴얼 있는 7명은 카드에 맵 버튼 + 진행도(빈칸/작성 중/완료), 나머지는 "매뉴얼 준비 중"
- agent.html?id=neon&map=haven — 맵별 매뉴얼 페이지
- 공통: 서버 없이 더블클릭으로 열림, 다크 테마, 폰에서도 보기 좋게, "AI 초안" 카드엔 작은 배지
- playbook.md — 요원 카드를 노션에 붙여넣기 좋은 마크다운으로
- REVIEW.md — 확신 낮은 팁, 비운 칸, 🔍 대체 영상, 표본 부족 조합, 참고한 웹 출처

## 7. 진행 순서
1) API로 데이터·패치 받고 현재 맵 풀 후보를 보여준다 → 코치가 맵 확정.
2) 좌표 확인: 헤이븐 미니맵에 코치 데이터 점을 찍어서 보여준다. 벽 밖으로 튀면 변환식을 찾고 코치 OK 받기 전엔 다음으로 넘어가지 않는다.
3) 파일럿: 네온 카드 + 네온 × 헤이븐 매뉴얼 페이지(A 자동 생성 + B 빈 틀)만 만들고 브라우저로 열어준 뒤 멈춘다. 코치가 구조·톤 보고 고쳐준다.
4) OK하면: 7명 카드 → 7명 × 확정 맵 페이지 → 나머지 전 요원 카드.
   서브에이전트로 병렬 처리해도 되지만 data/*.js 합치기는 메인이 한 번에.
5) 셀프 검수 후 3~5줄 보고: 스킬명·키 API와 일치 / js 문법 오류 없음 / 모든 페이지 링크 동작 / 히트맵 수·"데이터 없음" 수 / 영상 oEmbed 통과 수·🔍 수 / REVIEW 항목 수.

## 8. 유지보수 규칙
- "네온 헤이븐 공격 셋업에 이 ValoPlant 링크: ..." → manual.js만 수정하고 그 칸 상태 갱신.
- "○○ 팁에 △△ 추가해" → agents.js만 수정.
- "○○ ○○맵 매뉴얼 틀 만들어줘" → 해당 요원 × 맵만 추가하고 카드에 맵 버튼 연결.
- "데이터 바꿨어, 히트맵 다시 만들어" → scripts/로 히트맵·승률표·출처 날짜 다시 생성. 코치가 쓴 칸은 건드리지 않는다.
- "패치 갱신해" → API 다시 받아 스킬명·아이콘·신규 요원만 반영. "패치노트 보고 영향 받는 카드 찾아줘" → REVIEW.md에 확인 목록만.
- "검수 완료"인 카드·페이지는 코치 허락 없이 바꾸지 않는다.
