3. 조작

  • S — 새 장면: 영상 정지 + 캡처 + 메모창 + 녹음 시작
  • Shift+S — 직전 장면의 부연: 001-1, 001-2 처럼 별도 항목으로 만들되 001 밑에 묶임. 한 라운드를 여러 장면으로 쭉 해설할 때
  • 말하는 중 S 한 번 더 — 지금까지 말한 걸 저장하고, 지금 화면으로 부연(001-1)을 새로 만들어 이어서 말하기. 라운드 해설을 장면별로 끊어가며 할 때
  • Enter — 녹음 끝 → 한 번 더 Enter 저장 · Esc 취소
  • 목록에서 자세히 — 여러 줄 메모, 그림별 설명, 그림 추가/삭제
  • 목록에서 줄 클릭 후 Ctrl+V — 캡처 붙여넣기 (Win+Shift+S 로 영역 캡처 추천)
  • #번호 끌어서 순서 변경 · ✥ 끌어서 도구 위치 이동
  • HTML — 이미지까지 박힌 보고서 1장으로 출력

4. 저장 위치

  • 스크린샷 원본 → 다운로드 폴더. 바탕화면 관전캡처 정리로 경기별 폴더 정리
  • 메모·목록 → 브라우저 저장소(유튜브 도메인). 사이트 데이터를 지우면 날아갑니다
  • 그림 사본 → 브라우저 IndexedDB (HTML 내보내기·노션 적재에 사용)
