장면 캡처 도구 — 크롬 확장판 v1.0 설치 방법
==========================================

[설치] (1분)
1. 크롬 주소창에  chrome://extensions  입력
2. 오른쪽 위 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 폴더(clip-extension)를 선택
5. 퍼즐 아이콘(확장 프로그램) → 장면 캡처 도구 옆 핀 📌 눌러서 고정

[처음 한 번]
- 유튜브 영상 페이지를 새로고침하면 도구가 자동으로 뜹니다 (북마크 안 눌러도 됨).
- 예전 북마크 도구로 쌓은 메모·그림은 처음 켤 때 자동으로 옮겨옵니다.
- 옮겨진 걸 확인했으면 북마크바의 예전 "장면 저장 도구" 북마크는 지우세요.
  (둘 다 켜면 도구가 두 개 뜹니다)
- 크롬 설정 → 다운로드 → "다운로드 전에 각 파일의 저장 위치 확인" 은 꺼두세요.

[달라진 점]
- 캡처 파일: 다운로드/관전캡처/경기 제목 [영상ID]/ 에 바로 저장
  → 바탕화면 "관전캡처 정리"는 이제 안 써도 됩니다.
- 메모 저장: 확장 프로그램 저장소 (쿠키·사이트 데이터 지워도 안 날아감)
- 자동 백업: 메모가 바뀌면 30분마다 다운로드/관전캡처/_백업/ 에 저장
- 받아쓰기: 서버가 켜져 있으면 지금처럼 whisper,
            꺼져 있으면 브라우저 음성인식으로 자동 전환
- 확장 아이콘 또는 도구의 ⚙ 버튼 → 관리 페이지 (설정 · 백업 · 영상 목록)

[고친 버그]
- 빨간 "장면 저장" 버튼을 마우스로 누르면 부연으로 저장되던 문제
- 부연(001-1)·추가 사진·붙여넣은 그림이 정리 폴더로 안 옮겨지던 문제

[v1.2.0 — 라운드 자동 찾기]
- 유튜브 경기 영상 아래에 "🎯 라운드" 막대가 생깁니다 → "라운드 자동 찾기"
- 중계 화면 위쪽 점수판(시계·점수)을 읽어서 라운드마다
  ① 시작 시점(배리어 5초 전)을 찾고  ② 1:30 · 1:00 미니맵을 자동으로 찍습니다
- 끝나면 R1 R2 … 버튼: 누르면 그 라운드로 이동 / 마우스를 올리면 미니맵 / [ ] 키로 이전·다음
- "🗂 미니맵 모아보기": 라운드별 미니맵을 한 페이지에 (관리 페이지에도 목록)
- 그림 파일: 다운로드/관전캡처/경기 제목 [영상ID]/라운드/
- v1.2.1: 찾는 동안 화질을 1080p로 고정(낮은 화질에서 숫자를 잘못 읽던 문제), 잘못 읽은 점수 버리기,
          빠진 라운드 다시 찾기, 1:00 전에 끝난 라운드는 '끝나기 직전' 화면, 두 자리 점수 붙어 보이는 문제
- 모아보기 페이지: 라운드마다 해석 메모(자동 저장) + 그 라운드에 저장한 장면(S) 목록
  "📄 자료로 내보내기" → 라운드/라운드정리.html(그림 포함) · .md · .json
- 찾을 때마다 라운드/_진단.json 이 같이 저장됩니다 (잘 안 잡히면 Claude에게 이 파일을 보여주세요)
- 주의: 찾는 동안 그 창을 켜 둬야 합니다(다른 탭·최소화하면 영상이 안 불러와져요)
        VCT 2026 공식 중계 화면 기준. 다른 중계·너무 낮은 화질(480p 이하)은 못 읽을 수 있어요

[v1.11.0 — 분석 화면 (가볍게 다시 정리)]
- 유튜브 도구 막대: 목록 · 분석 열기 · ⚙ 만. 나머지(분석 모드·받아쓰기·깔끔 화면·내보내기·관리)는 ⚙ 안에
- 메모는 글로 쓰기가 기본. 말로 적고 싶을 때만 메모창의 "🎤 말하기" (누르면 영상이 멈춤)
- "분석 열기" → 지금 보는 라운드로 분석 화면이 열립니다
  왼쪽 라운드 · 가운데 그림(화살표·원·펜·글자) · 아래 줄(미니맵·장면·붙인 스크린샷) · 오른쪽 메모
  Ctrl+V 스크린샷 붙이기 · ↑↓ 라운드 · ←→ 그림 · D 나란히 보기 · Ctrl+Z 되돌리기
- "PPT로 보내기": 그린 것·붙인 스크린샷까지 정리 슬라이드로 / "📋 텍틱 시트로": 고른 그림 1장
- 빈 맵 보드: 분석 화면 위 "빈 맵 보드" (자주 안 쓰는 버튼은 보드의 "더보기 ▾" 안)
- 받아쓰기 교정: 관리 페이지 → 설정 → "자주 틀리는 말 고치기" 에  틀린 말 = 바른 말
- 받아쓰기를 더 정확하게: won-tools\asr\받아쓰기 정확도 올리기 (큰 모델 받기).bat (약 1.1GB, 한 번만)

[업데이트할 때]

- 저장된 메모는 그대로 유지됩니다. (확장을 "삭제"하면 메모도 지워지니 주의)
