설정 저장됨

브라우저 음성인식은 따로 설치할 게 없지만, 요원·맵 이름 같은 게임 용어는 서버 방식보다 덜 정확합니다.
경기마다 두 팀 이름·그 경기 요원·맵 이름은 자동으로 알려 줘요. 여기엔 코치님이 자주 쓰는 말만 적으면 됩니다.
받아쓰기 바로 뒤에 자동으로 바뀌어요 (받아쓴 원문은 장면에 따로 남음). 하버공→하버 궁, 삐팝→B팝, 알람보→알람봇 같은 건 이미 들어 있어요.
캡처는 다운로드/관전캡처/경기 제목 [영상ID]/ 에 바로 저장됩니다.
크롬 설정에서 "다운로드 전 저장 위치 확인"이 켜져 있으면 저장할 때마다 창이 뜹니다. 꺼두는 걸 권장합니다.

🎯 스크랩한 경기

불러오는 중…
유튜브 경기 영상 아래 막대에서 "라운드 자동 찾기"를 누르면 여기 쌓입니다. 빠진 라운드 = 방송이 그 라운드 내내 점수판을 가려 못 찾은 번호 · 1:25 없음 = 그 순간 리플레이·그래픽이 미니맵을 가림 · 보드 = 만든 보드 수 / 찍은 미니맵 수. 미니맵 그림 파일은 경기 폴더 안 라운드 폴더에도 있어요.
📱 태블릿 북마크 가져오기 (지금은 안 쓰는 기능 — 필요할 때 펼치기)

디스코드 메시지를 그대로 붙여넣으세요 — 태블릿 ★ 북마크, 시점(?t=) 붙은 유튜브 링크, 또는 영상 링크 한 줄 + 그 아래 "12:34 메모" 줄들 모두 됩니다. 유튜브 영상 화면에서 Ctrl+V 해도 됩니다.

가져온 북마크는 "화면 대기" 상태예요. 목록의 경기를 열면 그 시점 화면이 원본 화질로 자동 캡처됩니다.
