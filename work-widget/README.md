# 근무 위젯 — 화면 오른쪽에 붙는 시간표

<img src="icon.png" width="96" alt="근무 위젯 아이콘 (헤드셋 쓴 코치 강아지)">

컴퓨터를 켜면 **화면 오른쪽에 좁은 창으로 근무 시간표가 저절로 열립니다.**
시간표 페이지는 claude.ai 의 비공개 링크(코치 계정만 열림)라서, 이 폴더에는 그 창을 띄워 주는 설치 파일만 들어 있습니다.

위젯에서 할 수 있는 것

- 달력 + 오늘 일정 (구글 캘린더·노션 '내 일정'을 그대로 읽음)
- **오늘 몸 관리**: 식사 1~4끼, 헬스 1시간, PT 체크 → 노션 '💪 식단·운동 기록'에 날마다 한 줄
  - 기본 식단 `닭가슴살 200g · 밥 200g · 야채 조금`, 출근날(오프라인 근무가 있는 날)은 `회사밥`
  - PT 는 노션 '내 일정'에 종류 `PT·운동`으로 넣은 날에 시간과 함께 나옴
  - 이번 주 헬스 일수 · 식사 끼니 · PT 횟수 합계
- 할 일 (노션 '✅ 할 일' 읽기·체크·추가)
- 일정 추가·고치기 ("내일 오후 3시 PT 1시간"처럼 한 줄로 적기)
- 일정을 누르면 메모

## 받기

**PC(윈도우)에서** GitHub 의 `work-widget/WorkWidget.bat` 을 열고 오른쪽 위 **다운로드(↓, Download raw file)** 버튼을 누르세요.

크롬이 "위험할 수 있는 파일"이라고 하면 **계속** 또는 **유지**를 누르세요(`.bat` 파일이라 나오는 기본 경고입니다).

## 설치(한 번만)

1. `WorkWidget.bat` 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
2. "준비됐어요!" 창이 뜨면 끝입니다.
   - 바탕화면에 강아지 아이콘 **WON 근무 위젯** 이 생깁니다.
   - 시작프로그램에도 같은 바로가기가 들어가서, 컴퓨터를 켜면 위젯이 저절로 열립니다.
3. 처음 열 때는 claude.ai 로그인과 위젯 위쪽의 **허용하기**(구글 캘린더·노션)가 필요합니다.

다시 실행해도 괜찮습니다. 바로가기와 아이콘을 새로 덮어쓰기만 합니다.

## 쓰는 법

- 바탕화면 **WON 근무 위젯** 아이콘을 누르면 열립니다. 이미 열려 있으면 새로 열지 않고 오른쪽에 다시 붙입니다.
- 위젯 맨 위 **주간 시간표 | 달력 | 위젯** 으로 큰 화면과 오갈 수 있습니다.
- 달력에서 지난 날을 누르면 그날 몸 관리 체크도 고칠 수 있습니다(앞으로 올 날은 그날 체크).
- 새 내용이 안 보이면 위젯 창에서 `F5`.

## 필요한 것

- 윈도우 10/11, 크롬(없으면 엣지로 엽니다)
- claude.ai 에 구글 캘린더·노션 커넥터가 연결된 코치 계정

## 지우기(삭제)

- 바탕화면과 시작프로그램(`Win+R` → `shell:startup`)의 **WON 근무 위젯** 바로가기를 지웁니다.
- `%LOCALAPPDATA%\WON` 폴더의 `open-widget.ps1`, `won-widget-dog2.ico` 를 지웁니다.

노션·구글 캘린더의 일정과 기록은 그대로 남습니다.
