# 조준선의 밤 산책 — 스토리보드

30초 · 16:9 (1920×1080) · Canvas 2D + 순수 JS · 외부 파일 0개

## 그림체

- 종이 질감(고정 시드로 만든 결·점) 위에 손그림 선. 캐릭터 선은 1/8초마다 미세하게 떨리는 '보일링' 효과를 넣고(떨림도 `t`로 정함), 배경은 셀 애니메이션의 배경 그림처럼 고정한다.
- **고정 팔레트 6색**

  | 이름 | 값 | 용도 |
  |---|---|---|
  | 종이 크림 | `#F1E6D0` | 바탕, 얼굴 안쪽, 하이라이트 |
  | 잉크 | `#2B2733` | 선, 그림자 |
  | 캐릭터 주황 | `#F26A21` | 조준선 캐릭터, 꼬리 |
  | 과녁 빨강 | `#C8433A` | 과녁, 커튼 |
  | 밤 남색 | `#1F2C55` | 밤하늘, 실내 어둠 해칭 |
  | 달빛 노랑 | `#F5D46A` | 달, 별, 바닥 달빛 |

- 명암은 반투명이 아니라 해칭선 밀도로 표현한다(`globalAlpha`는 항상 1).

## 캐릭터

주황 링 + 십자 틱 4개. 위 틱은 더듬이, 좌우 틱은 팔이고 아래 틱은 두 다리로 갈라진다. 링 안에 눈·눈썹·입이 있고, 조준선 중심점이 코다.
`crossForm` 값(0~1)으로 '그냥 조준선인 척' 모드와 '캐릭터' 모드 사이를 연속으로 오간다.

## 규칙

- 모든 움직임은 `render(t)` 하나로 정한다. 같은 `t`면 항상 같은 그림이 나온다.
- 키프레임 사이는 시작·끝 속도가 0인 easing(smootherstep)으로 이어서 표정·자세가 연속으로 바뀌게 한다.
- 별 배치, 종이결, 노이즈 버퍼는 모두 고정 시드 PRNG로 만든다.
- 소리(Web Audio API): 까치발·착지·나무 상자 발소리, 실내 외풍 → 창문 열림 돌풍 → 발사 휘익 → 밤바람. 발소리 타이밍은 걷기 위상(발이 바닥에 닿는 순간)에서 계산한다.
- MP4: 헤드리스 Chromium으로 30fps × 900프레임을 찍고, 같은 오디오 그래프를 OfflineAudioContext로 렌더링해서 FFmpeg로 합친다.
