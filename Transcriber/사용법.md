## 1. 녹음하기

### 온라인 수업 (화/수/토, 디스코드)

1. 시작 메뉴에서 **"녹음기"** 검색 후 실행
2. 수업 시작할 때 녹음 버튼 누르기
3. 끝나면 정지

디스코드가 마이크를 쓰는 중에도 동시에 녹음됩니다. 충돌 없습니다.
내 목소리만 녹음되므로 학생 음성 관련 개인정보 문제가 생기지 않습니다.

**파일을 옮길 필요 없습니다.** 윈도우 녹음기 기본 저장 폴더(`문서\사운드 레코딩`)를
스크립트가 자동으로 찾아서 처리합니다.

그리고 **전사가 끝나면 원본 녹음 파일을 `녹음\` 폴더로 자동으로 옮깁니다.**
파일이 사라지는 게 아니라 위치만 바뀝니다. 이유는 두 가지입니다.

1. **OneDrive 밖으로 빼내기 위해.**
   이 PC는 `문서` 폴더가 `C:\Users\elsha\OneDrive\Documents` 로 리디렉션돼 있습니다.
   그대로 두면 수업 녹음이 개인 클라우드로 올라갑니다.
2. 녹음 파일이 한곳에 모여서 나중에 찾기 쉽습니다.

같은 이름이 이미 있으면 `녹음_1.m4a`, `녹음_2.m4a` 처럼 번호가 붙습니다.
파일을 직접 끌어다 놓거나 `녹음` 폴더에 직접 넣은 경우에는 이동하지 않습니다.

### 오프라인 수업 (월/일)

폰 기본 녹음기로 녹음 -> PC로 옮겨서 `녹음` 폴더에 넣으면 끝입니다.
아이폰 `.m4a`, 안드로이드 `.m4a`/`.mp3` 전부 그대로 처리됩니다.

### 중요: 긴 수업은 반드시 끊어서 녹음하세요

윈도우 녹음기는 중간 저장을 하지 않습니다.
앱이 꺼지거나 PC가 멈추면 **그때까지 녹음한 것이 통째로 사라집니다.**
토요일 8시간 수업이 가장 위험합니다.

-> **쉬는 시간마다 한 번 끊고 새로 시작하세요.**
파일이 2~3개로 나뉘어도 스크립트가 알아서 전부 처리합니다.
사고가 나도 한 토막만 잃습니다.

### 중요: 녹음 끝나자마자 이름을 바꾸세요

녹음기가 붙이는 기본 이름으로는 무슨 반인지 알 수 없습니다.
파일이 20개쯤 쌓이면 못 찾습니다. 나중에 몰아서 하려 하면 이미 기억이 안 납니다.

```
2026-09-18_VAL_화수반.m4a
2026-09-20_VAL_토요반_1교시.m4a
2026-09-20_VAL_토요반_2교시.m4a
```

결과 텍스트가 같은 이름으로 생기므로, 이름만 잘 지어두면 찾기가 훨씬 쉽습니다.

## 2. 전사하기

**기본 (아무것도 안 옮겨도 됨)**
1. 바탕화면 **'수업 전사'** 더블클릭
2. 윈도우 녹음기 폴더에서 새 녹음을 찾으면 목록을 보여주고 물어봅니다
   -> 그냥 Enter 치면 진행, `n` 입력하면 건너뜀
3. 끝날 때까지 기다린다 (결과 폴더가 자동으로 열립니다)

**폰 녹음이나 다른 파일**
- `녹음` 폴더에 넣고 실행
- 또는 파일을 `Transcribe.bat` 아이콘 위로 끌어다 놓기

이미 전사한 파일은 자동으로 건너뜁니다. 중간에 끊겨도 다시 실행하면 이어서 합니다.
같은 파일을 두 번 처리하는 일은 없습니다.

### 걸리는 시간 (RTX 4070 SUPER 기준, 실측 23배속)

| 수업 길이 | 예상 소요 |
|---|---|
| 1시간 | 약 3분 |
| 4시간 (화/수 수업) | 약 10분 |
| 8시간 (토요일 수업) | 약 20분 |

GPU를 쓰므로 돌리는 동안 게임은 피하는 게 좋습니다.
수업 끝나고 걸어두고 자리 비우면 딱입니다.

### 결과물

전사본이 **두 곳에 생깁니다.**

1. `전사\` 폴더 (원본 보관)
2. **`바탕화면\수업\전사\`** (자동 복사)

Claude에 넣을 때는 바탕화면 쪽에서 바로 끌어다 쓰면 됩니다. 폴더 위치를 찾을 필요가 없습니다.

타임스탬프가 붙은 텍스트 형태입니다.

```
[00:00.000 --> 00:07.700]  존경하는 국민 여러분, 당원 여러분, ...
[00:08.360 --> 00:12.160]  중도와 수도권에서 이길 수 있는 후보입니다.
```

## 4. 용어집 관리

`용어집.txt` 를 메모장으로 열어 한 줄에 하나씩 단어를 적으면
음성 인식이 그 단어를 우선해서 인식합니다.

자주 틀리는 단어만 넣고, 나머지 교정은 Claude 정리 단계에서 하는 게 효율적입니다.

운영 요령: 전사 결과를 보다가 계속 틀리는 단어가 보이면 그때 추가하세요.
처음부터 다 채우려 하지 않아도 됩니다.

## 5. 알아둘 점

### 음성만으로는 복원이 안 되는 부분이 있습니다

게임 화면을 보며 하는 수업이라 전사본이 이렇게 나옵니다.

> "자 여기서 이렇게 들어가면 안 되고, 저 각을 먼저 봐야지"

**해결책: 상황이 바뀔 때마다 소리 내어 선언하는 습관.**
"자, B사이트 리테이크 볼게" 한마디면 전사본에 앵커가 박혀서
나중에 정리 품질이 확연히 달라집니다. 비용 0원인데 효과가 가장 큽니다.

더 확실하게 하려면 OBS로 화면까지 같이 녹화하고,
타임스탬프로 되짚는 방법이 있습니다. 대신 용량이 큽니다.

### 학생 목소리는 안 들어갑니다

지금 설정은 내 마이크만 녹음합니다.
나중에 "이 학생이 어디서 막혔나"까지 잡고 싶어지면
OBS로 디스코드 소리를 별도 트랙으로 녹음하는 방식으로 확장하면 됩니다.
그때는 미성년자 음성 녹음에 대한 사내 규정 확인과 사전 고지가 필요합니다.

### 녹음은 일단 다 해두세요

녹음 파일은 공짜고 사라지지 않습니다.
정리를 나중에 하더라도 녹음만 해두면 언제든 처리할 수 있습니다.
안 한 녹음만 영영 돌아오지 않습니다.

## 왜 폴더 이름이 영문(ClassRecord)인가요

이 PC는 **시스템 로캘이 en-US(ANSI 코드페이지 1252)** 로 설정돼 있습니다.
그래서 바탕화면 바로가기를 만드는 윈도우 구형 기능(WScript.Shell COM)에
한글 경로를 넘기면 전부 `?` 로 깨져서 바로가기 생성이 실패합니다.

폴더와 실행 파일 이름만 영문으로 두면 이 문제가 사라집니다.
바탕화면 아이콘 이름은 한글(`수업 전사`)로 표시되므로 쓰는 데는 차이가 없습니다.

`녹음`, `전사` 폴더와 문서 파일은 PowerShell(유니코드)만 다루기 때문에
한글 이름 그대로 두어도 아무 문제가 없습니다.
