# 수업 전사본 정리 프롬프트

전사본 `.txt` 파일을 Claude에 첨부하고, 아래 프롬프트를 그대로 붙여넣으세요.
`[ ]` 부분만 그날 수업에 맞게 채우면 됩니다.

---

## 기본 프롬프트 (복붙용)

```
첨부한 파일은 내가 진행한 발로란트 코칭 수업의 음성 전사본이야.
내(코치) 목소리만 녹음된 것이고, 학생 발언은 들어있지 않아.

[ 수업 정보 ]
- 날짜: [2026-09-18]
- 반: [VAL 화/수 (19시)]
- 수업 형태: [온라인 / 오프라인]
- 참여 학생: [이름 나열]

[ 작업 ]
아래 순서대로 처리해줘.

1. 전사 오류 교정
   음성 인식이라 발로란트 용어가 틀리게 적힌 곳이 있어.
   문맥으로 명백한 것만 고치고, 고친 항목은 마지막에 목록으로 보여줘.
   (예: "오퍼레이더" -> "오퍼레이터", "리테익" -> "리테이크")
   애매하면 고치지 말고 그대로 두고 [확인필요]로 표시해.

2. 수업 내용 정리
   아래 형식으로 정리해줘.

   ## 수업 개요
   - 한 줄 요약
   - 실제 수업 진행 시간 (전사본 타임스탬프 기준)

   ## 다룬 주제
   | 타임스탬프 | 주제 | 핵심 내용 |
   (타임스탬프는 반드시 전사본에 있는 실제 값만 사용)

   ## 핵심 지도 내용
   개념별로 묶어서. 내가 실제로 말한 표현을 최대한 살려서.

   ## 학생별 언급
   내가 이름을 부르며 지적하거나 칭찬한 내용만.
   이름이 안 나온 지적은 여기 넣지 말고 '핵심 지도 내용'에 둘 것.

   ## 반복해서 강조한 것
   2번 이상 나온 내용.

   ## 다음 수업 / 과제
   전사본에서 언급된 것만.

   ## [확인필요]
   - 지시대명사 때문에 상황 복원이 안 되는 부분 (예: "여기서 이렇게" 만 있고 맥락 없음)
   - 전사가 깨져서 무슨 말인지 모르겠는 부분
   - 내 기억으로 보충해야 할 부분

[ 절대 규칙 ]
- 전사본에 없는 내용은 절대 만들어내지 마.
  안 한 피드백, 안 나온 학생 이름, 추측한 라운드 상황 전부 금지.
- 불확실하면 채우지 말고 [확인필요]에 넣어.
- 내가 안 쓴 코칭 용어로 바꿔 쓰지 마. 내 말투를 유지해.
- 분량 채우려고 일반론("기본기가 중요합니다" 같은 것) 붙이지 마.
```

## 확장 프롬프트

### 주간 알림장 초안까지 뽑을 때

기본 프롬프트 결과가 나온 뒤에 이어서:

```
위 정리에서 [반 이름] 학부모용 주간 알림장 초안을 만들어줘.
- 위 정리에 있는 사실만 사용. 없는 내용 추가 금지.
- 학생별로 실제 언급된 것만 쓰고, 언급 없는 학생은 "이번 주 개별 코멘트 없음"으로 비워둬.
- 부정적 지적은 개선 방향과 함께.
- 초안이니까 내가 검토할 수 있게 근거 타임스탬프를 각 항목 옆에 달아줘.
```

### 노션 수업일지 DB에 넣을 때

```
위 정리를 노션 '수업 일지' DB에 넣을 형태로 바꿔줘.
- 먼저 초안을 보여주고, 내가 확인하면 그때 노션에 올려줘.
- 한글 자모가 깨질 수 있으니 올린 뒤 페이지 링크를 주고 내가 직접 확인할 수 있게 해줘.
```

### 여러 수업을 한 번에 볼 때

```
이번 주 전사본 [N]개를 첨부했어.
반별로 무엇을 다뤘는지 비교표를 만들고,
내가 반복해서 강조한 개념 / 특정 반에서만 다룬 개념을 구분해줘.
사실만. 없는 내용 금지.
```

## 팁

- **전사본이 길면(4시간 이상)** 앞부분부터 순서대로 나눠서 넣는 게 정확도가 높습니다.
- **타임스탬프를 꼭 살려두세요.** 나중에 원본 녹음이나 화면 녹화를 되짚을 때 유일한 단서입니다.
- **[확인필요] 목록이 매번 길게 나온다면** 수업 중 상황 선언("자, B사이트 리테이크 볼게") 습관을 들이면 확 줄어듭니다.
