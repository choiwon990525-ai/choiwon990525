# ClassPen — 수업용 화면 판서 도구

에픽펜(Epic Pen)처럼 **지금 보고 있는 화면 위에 바로 그리는** 윈도우용 도구입니다.
리플레이·VOD·맵을 띄워 놓고 동선, 스모크 위치, 각도를 그려서 설명할 때 씁니다.

- 펜 · 형광펜 · **레이저 펜**(그리고 나면 잠시 후 저절로 사라짐)
- 직선 · 화살표 · 사각형 · 원 · 텍스트(한글 입력 됨) · 지우개
- 8가지 색(발로란트 공격 빨강·수비 청록 포함), 굵기 3단계
- 실행 취소 / 다시 실행, 전체 지우기, 화이트보드·블랙보드
- 화면 캡처 → 클립보드 복사(디스코드에 바로 Ctrl+V) + `사진\ClassPen` 폴더 저장
- **코치 시그니처 강아지** 내장: 바탕화면 아이콘·시작 화면, 툴바·트레이 아이콘, 강아지 도장, 캡처 워터마크
- **화면 공유·녹화에는 툴바가 안 보임** (학생들한테는 그림만 보여요)
- 듀얼 모니터와 화면 배율(125%·150%) 지원

설치 프로그램이나 인터넷 다운로드가 필요 없습니다. 윈도우 10/11에 기본으로 들어 있는 기능만 씁니다.

## 받기

**PC(윈도우)에서** 둘 중 편한 방법으로 받으세요.

- Claude 대화에 올라온 `ClassPen.bat` 파일 카드를 눌러 저장
- GitHub에서 `class-pen/ClassPen.bat` 을 열고 오른쪽 위 **다운로드(↓, Download raw file)** 버튼

크롬이 "위험할 수 있는 파일"이라고 하면 **계속** 또는 **유지**를 누르세요(`.bat` 파일이라 나오는 기본 경고입니다).
받은 파일은 어디에 둬도 됩니다. 처음 실행하면 바탕화면에 강아지 아이콘이 생겨요.

## 실행하기

1. `ClassPen.bat` 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
   - 처음 한 번은 까만 창이 잠깐 뜨고 몇 초 동안 준비합니다.
2. 강아지 시작 화면이 잠깐 나온 뒤, 화면 왼쪽에 툴바가 나오고 작업 표시줄 오른쪽(트레이)에 강아지 아이콘이 생깁니다.
3. **처음 켜면 바탕화면과 시작 메뉴에 강아지 아이콘 `ClassPen` 이 생깁니다. 다음부터는 이 아이콘으로 켜세요.**
   까만 창 없이 바로 켜집니다. (`ClassPen.bat` 은 업데이트할 때만 다시 실행하면 됩니다.)
   - 아이콘이 안 보이거나 지웠다면: 작업 표시줄 오른쪽 트레이의 강아지 아이콘 **우클릭 → 바탕화면에 ClassPen 아이콘 만들기**

끄려면 툴바 오른쪽 위 **×** 를 누르거나 트레이 아이콘 → **종료**를 누르면 됩니다.

## 쓰는 법

- **펜 같은 도구를 고르면 그리기 모드**가 됩니다. 이때는 마우스가 그림판에 그려요.
- **마우스(화살표 모양) 버튼이나 Esc**를 누르면 그림은 그대로 남고, 클릭은 아래 화면(영상, 게임)으로 갑니다.
- 영상을 멈추고 → 그리고 → Esc로 마우스 모드 → 재생 → `Ctrl+Alt+C`로 지우기. 이 순서가 기본입니다.
- 툴바 빈 곳을 끌면 옮길 수 있고, 더블클릭하거나 **⌃** 를 누르면 작게 접힙니다.

### 어디서나 되는 단축키

| 단축키 | 기능 |
|---|---|
| `Ctrl+Alt+D` | 그리기 ↔ 마우스 전환 |
| `Ctrl+Alt+L` | 레이저 펜 켜기/끄기 |
| `Ctrl+Alt+Z` | 실행 취소 |
| `Ctrl+Alt+C` | 전체 지우기 |
| `Ctrl+Alt+H` | 툴바 숨기기 / 보이기 |
| `Ctrl+Alt+S` | 화면 캡처 (클립보드 + 사진 폴더) |

### 그리기 모드일 때 단축키

| 키 | 기능 | 키 | 기능 |
|---|---|---|---|
| `P` | 펜 | `R` | 사각형 |
| `H` | 형광펜 | `O` | 원 |
| `L` | 레이저 펜 | `T` | 텍스트 |
| `I` | 직선 | `E` | 지우개 |
| `A` | 화살표 | `S` | 강아지 도장 |
| `Esc` | 마우스 모드 | | |
| `1`~`8` | 색 바꾸기 | `[` `]` | 굵기 |
| `B` | 화이트보드 → 블랙보드 → 투명 | `Delete` | 전체 지우기 |
| `Ctrl+Z` | 실행 취소 | `Ctrl+Y` | 다시 실행 |

- `Shift` 를 누른 채 그리면 직선·화살표는 45° 단위로, 사각형·원은 정사각형·정원으로 그려집니다.
- 텍스트: 원하는 곳을 클릭하고 입력 → `Enter` 완료, `Shift+Enter` 줄바꿈, `Esc` 취소.
- 지우개는 닿은 획을 통째로 지웁니다.

## 시그니처 강아지

코치 시그니처 강아지(헤드셋 쓴 흰 강아지)가 **프로그램 안에 들어 있어서** 따로 그림 파일이 없어도 나옵니다.

- 바탕화면·시작 메뉴 아이콘, 켤 때 나오는 시작 화면, 툴바 맨 위, 트레이 아이콘이 강아지입니다.
- 도구에 **강아지 도장**(`S`)이 있습니다. 누른 곳에 강아지가 찍히고, 크기는 굵기 버튼(작게·보통·크게)으로 정합니다.
  지우개·실행 취소로 지울 수 있어요.
- 화면 캡처 오른쪽 아래에 강아지가 들어갑니다. 빼고 싶으면 트레이 아이콘 → **캡처에 강아지 넣기** 체크를 끄세요.

다른 표정·그림으로 바꾸고 싶으면 배경을 지운 PNG 를 `강아지.png` 이름으로 `ClassPen.bat` 옆에 두고,
ClassPen 을 끈 뒤 다시 실행하세요. 그 파일을 치우면 기본 강아지로 돌아갑니다.

> GitHub 페이지에서 `ClassPen.bat` 을 열면 프로그램 코드(글자)만 보입니다. 강아지는 PC에서 실행했을 때 화면에 나옵니다.

## 수업할 때 알아 둘 것

- **디스코드 화면 공유는 '화면'(모니터 전체)으로** 공유해야 학생들에게 그림이 보입니다.
  특정 창(게임 창, 크롬 창)만 공유하면 그림이 안 나가요. OBS도 '디스플레이 캡처'를 쓰세요.
- **게임 위에 그릴 때는 발로란트 화면 모드를 '창 모드 전체화면'(테두리 없는 창)** 으로 두세요.
  '전체 화면'(독점 전체화면)에서는 윈도우가 그림판을 게임 뒤로 숨깁니다.
- 툴바는 기본으로 화면 공유·녹화에 안 찍힙니다(윈도우 10 2004 이후). 보이게 하고 싶으면
  트레이 아이콘 → **화면 공유·녹화에 툴바 안 보이기** 체크를 끄세요.
- 툴바를 실수로 숨겼으면 `Ctrl+Alt+H` 를 누르거나 트레이 아이콘을 더블클릭하세요.
- 한 번 더 `ClassPen.bat` 을 실행해도 두 개가 켜지지 않고, 숨겨 둔 툴바가 다시 나타납니다.

## 문제가 생기면

- **단축키가 안 먹을 때**: 다른 프로그램이 같은 단축키를 쓰고 있으면 시작할 때 알림이 뜹니다.
  그 단축키만 꺼지고 나머지는 정상 동작합니다.
- **빌드 실패 / 오류 창**: 까만 창에 나온 내용을 캡처해서 보내 주세요.
- **백신이 막을 때**: `ClassPen.bat` 은 윈도우 기본 C# 컴파일러로 `ClassPen.exe` 를 만듭니다.
  백신이 이 과정을 의심하면 허용해 주세요. 코드는 이 파일 안에 그대로 들어 있습니다.

## 지우기(삭제)

프로그램을 끈 뒤 아래 두 폴더를 지우면 깨끗하게 없어집니다.

- `%LOCALAPPDATA%\ClassPen` — 만들어진 프로그램
- 바탕화면과 시작 메뉴의 `ClassPen` 바로가기
- `%APPDATA%\ClassPen` — 툴바 위치·색 같은 설정

캡처한 이미지는 `사진\ClassPen` 폴더에 남아 있습니다.
